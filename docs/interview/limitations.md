# MotionEdge-F103 项目边界与不足

## 1. 单 IMU，不是外部机械反馈闭环

边界：MPU6500 测量手持板，SG90 不带动它。原因：当前目标是验证姿态感知、控制计算和安全输出链。升级：搭建单轴平台，把 IMU 固定到被控机构，或增加输出侧编码器，再定义超调、调节时间和稳态误差。

## 2. 没有绝对 Yaw

边界：输出 Roll/Pitch，不提供长期绝对 Yaw。原因：六轴 IMU 没有磁力计，重力不能约束绕重力轴旋转。升级：加入磁力计、视觉或外部航向参考并完成标定与抗干扰验证。

## 3. 姿态参考受限

边界：0.352°/0.375° 是相对 iPhone 水平仪的 MAE，`REFERENCE_LIMITED`。原因：参考分辨率和不确定度未知。升级：使用可溯源角度台/倾角仪，记录安装误差和不确定度预算。

## 4. MQTT 是本地原型

边界：Mosquitto 绑定本地，无 TLS，不直接暴露公网。原因：当前验证设备模型、恢复和观测解耦，而不是安全云部署。升级：TLS、设备证书、ACL、密钥轮换和威胁模型。

## 5. PWM 电气抖动未测

边界：报告的是软件 PWM 指令/遥测统计，`PWM Electrical Jitter = NOT_TESTED`。原因：没有示波器或逻辑分析仪证据。升级：测量周期、脉宽抖动与供电扰动，区分软件指令和物理波形。

## 6. 无舵机电流遥测

边界：`Servo current telemetry = NOT_AVAILABLE`，不声称过流保护。原因：硬件没有电流传感器。升级：增加采样电阻/电流监测 IC 与独立硬件限流，不仅靠软件估计。

## 7. F103C8 资源有限

边界：v1.0.1 RAM 使用 17824/18944 B，剩余 1120 B。原因：静态任务栈、FreeRTOS heap、DMA/协议缓冲和安全模块都占用固定资源。升级：先做证据化预算；若加入 TLS、更复杂滤波或双 IMU，优先换更高资源 MCU。

## 8. 测试时长不是工业寿命

边界：已有 600 s、624.742 s 和 1800 s 阶段实验，不能推导年级寿命、温度/振动/EMC 或批量一致性。原因：测试覆盖功能和短时稳定场景。升级：定义环境矩阵、长时间 soak、故障率、硬件批次和认证计划。

这些是工程边界，不等于项目失败。主动陈述限制能够防止把有限证据扩张成不可验证的结论。
