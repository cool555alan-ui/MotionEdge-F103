# 舵机 PWM 安全标定

初始 `1000/1500/2000 µs` 只用于标定前的软件保护，不代表舵机真实机械0°～180°。2026-08-09使用SG90和独立5 V电源完成1500、1450、1550、1400、1600 µs逐点实机验证；五点均能安全动作，中间两点仅因位移较小记录为WARN，无嗡鸣、抖动或卡滞。以1400/1500/1600 µs作为已测保守范围，并在两侧各留50 µs裕量，正式固件窗口为`1450/1500/1550 µs`。该范围不表示机械极限，也不对应经过外部角度仪器标定的绝对角度。

后续更换舵机、电源或机械结构时，先验证小范围序列：1500、1450、1550、1400、1600 µs。不要直接测试1000/2000 µs。需要重新探索范围时运行：

```powershell
python -m motionctl actuator calibrate-range --port COM4 --step-us 25 --margin-us 50 --output artifacts/phase09/servo-calibration.json
```

工具每次只短时输出一个 25 或 50 µs 步进，随后自动回到 1500 µs，只有用户确认该步安全才继续。出现接近限位、堵转声、异常发热/电流、抖动或碰撞时立即停止。最终安全边界应在观察到的机械边界内再保留 50～100 µs 裕量。

本硬件没有舵机电流传感器，过流检测状态必须记录为 `NOT_AVAILABLE`。没有示波器或逻辑分析仪时，真实 PWM 周期、脉宽与抖动为 `NOT_TESTED`，不能用 CCR 软件值替代电气测量。
